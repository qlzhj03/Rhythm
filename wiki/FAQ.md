# 常见问题 (FAQ)

关于 Rhythm 音乐播放器的常见问题。

## 📥 安装与更新

### 我可以在哪里获取 Rhythm？

从源码自行构建 APK，详见[安装指南](Installation-Guide.md)。

### 如何更新 Rhythm？

- **应用内更新**：在 设置 → 更新 中开启自动更新
- **手动更新**：安装新版本 APK，覆盖现有应用

### 为什么无法安装更新？

如果出现"应用未安装"错误：
- **不同来源的应用签名不同**。请坚持使用同一种安装方式。
- 如果要更换来源，请先卸载，再全新安装。

## 🎵 音频与播放

### Rhythm 支持哪些音频格式？

**内置（平台解码器）：**
- 无损：FLAC、ALAC、WAV、PCM、AIFF
- 有损：MP3、AAC、Opus、Vorbis
- MIDI

**FFmpeg 解码（捆绑扩展）：**
- 无损：APE、WavPack、TAK、TTA、WMA Lossless
- 有损：WMA
- Dolby：AC-3、EAC3-JOC (Atmos)、AC-4

**取决于设备（需要硬件支持）：**
- DTS、DTS-HD MA、DTS:X
- DSD/DSF/DFF（需要兼容的 DAC）

📖 **完整详情：**[音频格式指南](Audio-Formats.md)

### 为什么我的音乐文件无法播放？

常见原因：
1. **不支持的格式** - 转换为 FLAC 或 MP3
2. **文件损坏** - 尝试用 VLC 播放以验证
3. **缺少权限** - 授予存储访问权限
4. **文件位置错误** - 确保文件位于可访问的文件夹中

### Rhythm 支持无缝播放吗？

支持！无缝播放适用于 FLAC、MP3、AAC 和 Opus 格式。

### 什么是响度均衡(ReplayGain)？

响度均衡(ReplayGain)会归一化音乐的感知响度。选择 **专辑增益 (Album Gain)** 可保持专辑内的动态范围，选择 **单曲增益 (Track Gain)** 则可让所有歌曲响度一致。在 设置 → 队列与播放 → 播放 → ReplayGain 中配置。

### Rhythm 支持交叉淡入淡出吗？

支持！交叉淡入淡出可将上一曲的结尾平滑过渡到下一曲的开头，时长可在 1–12 秒间调节。在 设置 → 队列与播放 → 播放 → 交叉淡入淡出 中配置。

### 我可以使用均衡器吗？

可以！Rhythm 包含：
- 10 段专业均衡器
- 6032+ 个针对设备优化的 AutoEQ 预设
- 导入/导出自定义配置文件
- 低音增强与虚拟化音效

### Rhythm 支持 USB DAC / 比特完美播放吗？

支持！Rhythm 原生支持 USB DAC：
- **Android 14+（比特完美模式）：** 启用 `App` 路由时，Rhythm 会在受支持的设备上通过原生 Android `setPreferredMixerAttributes` API 请求独占的比特完美 USB 路由。
- **为什么没有 USB 弹窗？** Rhythm 通过 Android 系统的原生高解析度音频通道播放音频，而不是使用自定义用户空间驱动绕过操作系统。由于走的是官方 API，DAC 会自动且静默地连接，不会显示 USB 权限对话框。

## 🎤 歌词

### 如何获取同步歌词？

Rhythm 从以下来源获取歌词：
1. **LRCLib**（在线、社区驱动）
2. **内嵌歌词**（来自音频文件元数据）

启用位置：设置 → 音频与音效 → 歌词

### 歌词不同步，如何修复？

- 点按播放器中的歌词设置图标
- 使用 +/- 按钮调整时间
- 为该特定曲目保存偏移量

### 我可以添加自己的歌词吗？

可以！使用 Mp3tag 等元数据编辑器，将 `.lrc` 格式的歌词嵌入到音频文件中。

---

## 🖼️ 专辑封面与元数据

### 专辑封面不显示？

解决方法：
1. 使用 Mp3tag 在音频文件中**嵌入封面**
2. **启用在线获取**：设置 → 通知与服务 → API 管理（Deezer、YouTube Music）
3. **清除缓存**：设置 → 应用 → Rhythm → 存储 → 清除缓存
4. **重新扫描音乐库**：设置 → 库与媒体 → 媒体扫描

### 我可以编辑歌曲元数据吗？

可以！Rhythm 支持完整的元数据编辑：
- 歌曲标题、艺术家、专辑、流派
- 音轨编号、年份
- 专辑封面
- 批量操作

长按歌曲 → 歌曲信息 → 编辑

需要存储写入权限。

### 为什么我无法编辑某些文件？

- SD 卡上的文件可能需要特殊权限
- 某些文件可能是只读的
- 尝试将文件移动到内部存储

## 📱 权限与隐私

### 为什么 Rhythm 需要存储权限？

用于访问并播放你的音乐文件。Rhythm 在 Android 11+ 上使用分区存储 (scoped storage) 以增强隐私保护。

### Rhythm 会收集我的数据吗？

**不会。** Rhythm 是 100% 自由开源软件(FOSS)且注重隐私：
- ✅ 无分析或跟踪
- ✅ 不收集个人数据
- ✅ 所有数据存储在本地
- ✅ 仅可选功能（歌词、封面）使用网络

### 我可以完全离线使用 Rhythm 吗？

可以！核心功能无需网络即可使用：
- 音乐播放
- 播放列表
- 均衡器
- 小部件
- **Rhythm Go** 下载的流媒体曲目

仅以下功能需要网络：
- 在线歌词（LRCLib）
- 专辑封面获取（Deezer）
- 应用更新
- 流媒体模式服务器连接

## 📊 功能

### Rhythm 有睡眠定时器吗？

有！从播放界面 → 菜单 → 睡眠定时器 进入。

### 我可以创建和管理播放列表吗？

可以！完整的播放列表支持：
- 创建/编辑/删除播放列表
- 重新排序歌曲（拖放）
- 多选移除
- 导入/导出（M3U、PLS 格式）
- 网格视图
- 智能排序选项

### Rhythm 支持 Android Auto 吗？

支持！Rhythm 支持 Android Auto。

### 有小部件吗？

有！提供多种小部件：
- **Glance 小部件**：音乐、Cookie、统计和歌词小部件，具有自适应响应式尺寸
- **实时更新**
- **播放控制**
- **可自定义外观**

### 我可以自定义主题吗？

可以！全面的主题定制：
- 浅色/深色/系统模式
- Material You 动态颜色（Android 12+）
- 自定义配色方案
- 字体选择
- Material Symbols 图标
- 节日季节性主题

### 有 A–Z 滚动条吗？

有！当你的音乐库超过一定数量时，歌曲、专辑和艺术家标签页右侧会出现字母滚动条。沿字母滑动手指即可跳转到以该字母开头的条目。

### 什么是 Rhythm Go？

Go 模式允许你将 Rhythm 连接到流媒体服务器（Subsonic、Navidrome、Jellyfin）。Rhythm Go 让你可以从流媒体服务器下载曲目以便离线播放。在 设置 → 高级 → 实验性功能 → Go 模式 中配置。

## 🔧 故障排除

### 应用不断崩溃，怎么办？

1. 更新到最新版本
2. 清除应用缓存（不是数据）
3. 检查存储空间（需要 500MB+ 可用空间）
4. 重启设备
5. 如果仍然存在，请向维护者反馈并附上日志

### 扫描后音乐库为空？

1. 授予存储权限：设置 → 应用 → Rhythm → 权限
2. 检查黑名单/白名单：Rhythm 设置 → 库与媒体 → 媒体扫描
3. 确认音乐位置（如 /Music 等标准文件夹）
4. 重新扫描媒体：设置 → 库与媒体 → 媒体扫描

### 小部件不更新？

1. 移除并重新添加小部件
2. 关闭电池优化：设置 → 应用 → Rhythm → 电池 → 不受限
3. 授予通知权限
4. 更新到最新版本

### 蓝牙自动播放不工作？

1. 启用：Rhythm 设置 → 队列与播放 → 播放 → 设备重连时恢复播放
2. 授予蓝牙权限
3. 确保设备已正确配对
4. 检查特定设备的设置

## 🌐 在线功能

### 什么是 LRCLib？

LRCLib 是一个社区驱动的同步歌词数据库。Rhythm 会在可用时从中获取同步歌词。

### Rhythm 会上传我的收听数据吗？

**不会。** 所有统计数据和数据都保留在你的设备上，不会上传到任何服务器。

### 为什么 Rhythm 需要网络访问？

仅用于可选功能：
- **LRCLib** - 同步歌词
- **Deezer API** - 专辑封面
- **YouTube Music API** - 专辑封面查询
- **应用更新** - 检查新版本

你可以通过防火墙屏蔽网络，以实现完全离线使用。

## 💾 备份与数据

### 如何备份我的播放列表？

设置 → 数据与存储 → 备份与恢复 → 创建备份到文件

或者将单个播放列表导出为 M3U/PLS 文件。

### 更新时会丢失数据吗？

不会！更新会保留：
- 播放列表
- 设置
- 统计数据
- 元数据编辑

请始终在现有应用之上覆盖安装更新（不要先卸载）。

### 我可以将数据转移到新设备吗？

1. 在旧设备上备份
2. 将备份文件复制到新设备
3. 在新设备上安装 Rhythm
4. 设置 → 数据与存储 → 备份与恢复 → 从文件恢复
