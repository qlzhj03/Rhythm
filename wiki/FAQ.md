# 常见问题 (FAQ)

关于 Rhythm 音乐播放器的常见问题。

## 📥 安装与更新

### 我可以在哪里获取 Rhythm？

从源码自行构建 APK，详见[安装指南](Installation-Guide.md)。

### 如何更新 Rhythm？

- **应用内更新**：在 设置 → 更新与信息 → 更新 中开启自动更新
- **手动更新**：安装新版本 APK，覆盖现有应用

> 2026-11 起 `applicationId` 为 `com.qlzhj.rhythm`（debug 为 `.debug`），旧 `chromahub.rhythm.app` 包无法原地更新；迁移前请先备份。详见[安装指南](Installation-Guide.md)。

### 为什么无法安装更新？

如果出现"应用未安装"错误：
- **不同来源的应用签名不同**。请坚持使用同一种安装方式。
- 如果要更换来源，请先卸载，再全新安装。

## 🎵 音频与播放

### Rhythm 支持哪些音频格式？

**内置（平台解码器）：**
- 无损：FLAC、ALAC、WAV、PCM、AIFF
- 有损：MP3、AAC、Opus、Vorbis
- MIDI

**FFmpeg 解码（捆绑扩展）：**
- 无损：APE、WavPack、TAK、TTA、WMA Lossless
- 有损：WMA
- Dolby：AC-3、EAC3-JOC (Atmos)、AC-4

**取决于设备（需要硬件支持）：**
- DTS、DTS-HD MA、DTS:X
- DSD/DSF/DFF（需要兼容的 DAC）

📖 **完整详情：**[音频格式指南](Audio-Formats.md)

### 为什么我的音乐文件无法播放？

常见原因：
1. **不支持的格式** - 转换为 FLAC 或 MP3
2. **文件损坏** - 尝试用 VLC 播放以验证
3. **缺少权限** - 授予存储访问权限
4. **文件位置错误** - 确保文件位于可访问的文件夹中

### Rhythm 支持无缝播放吗？

支持！无缝播放适用于 FLAC、MP3、AAC 和 Opus 格式。

### 什么是响度均衡(ReplayGain)？

响度均衡(ReplayGain)会归一化音乐的感知响度。选择 **专辑增益 (Album Gain)** 可保持专辑内的动态范围，选择 **单曲增益 (Track Gain)** 则可让所有歌曲响度一致。在 设置 → 队列与播放 → 播放 → ReplayGain 中配置。

### Rhythm 支持交叉淡入淡出吗？

支持！交叉淡入淡出可将上一曲的结尾平滑过渡到下一曲的开头，时长可在 1–12 秒间调节。在 设置 → 队列与播放 → 播放 → 交叉淡入淡出 中配置。

### 我可以使用均衡器吗？

可以！Rhythm 包含：
- 10 段专业均衡器
- 6032 条针对设备优化的 AutoEQ 预设
- 导入/导出自定义配置文件
- 低音增强与虚拟化音效

### Rhythm 支持 USB DAC / 高解析度输出吗？

支持。Rhythm 通过标准 Android 音频路由输出，在受支持设备上（Android 14+）使用系统 `setPreferredMixerAttributes` API 请求更合适的混音器属性；播放引擎还提供可选的 **float PCM 输出**与设备能力检测。应用按采样率 / 位深 / 编解码器显示音质徽章，但**没有**独立的「Hi-Res 模式」开关，实际输出规格取决于设备与 DAC。

- **为什么没有 USB 权限弹窗？** Rhythm 不使用自定义用户空间 USB 驱动，走的是系统官方音频通道，DAC 会静默连接。
- **如何确认能力**：可在设置中的设备能力页查看系统支持的格式、offload 与 ProAudio / 低延迟能力。

## 🎤 歌词

### 如何获取同步歌词？

Rhythm 支持多来源与优先级：
1. **在线歌词**：默认 BetterLyrics → Lyrically → LRCLib，可在设置中切换为 LRCLib 优先；解析器支持逐词歌词、Enhanced LRC（ELRC）与 TTML
2. **本地歌词**：音频文件内嵌歌词与同目录 `.lrc` 文件，离线时作为回退
3. **手动调整**：可为单曲保存同步偏移

> 在线歌词属于外部 API 集成，默认关闭且受「编译期 → 全局 → 单项」三层开关控制。启用位置：设置 → 音频与音效 → 歌词（或 API 管理）。

### 歌词不同步，如何修复？

- 点按播放器中的歌词设置图标
- 使用 +/- 按钮调整时间
- 为该特定曲目保存偏移量

### 我可以添加自己的歌词吗？

可以！使用 Mp3tag 等元数据编辑器，将 `.lrc` 格式的歌词嵌入到音频文件中。

## 🖼️ 专辑封面与元数据

### 专辑封面不显示？

解决方法：
1. 使用 Mp3tag 在音频文件中**嵌入封面**
2. **启用在线获取**：设置 → 通知与服务 → API 管理（Deezer、YouTube Music）
3. **清除缓存**：设置 → 应用 → Rhythm → 存储 → 清除缓存
4. **重新扫描音乐库**：设置 → 库与媒体 → 媒体扫描

### 我可以编辑歌曲元数据吗？

可以！Rhythm 支持完整的元数据编辑：
- 歌曲标题、艺术家、专辑、流派
- 音轨编号、年份
- 专辑封面
- 批量操作

长按歌曲 → 歌曲信息 → 编辑

需要系统授予对应文件的写入权限；在较新 Android 版本上由系统文件授权流程处理（Rhythm 不申请 `MANAGE_EXTERNAL_STORAGE`）。

### 为什么我无法编辑某些文件？

- SD 卡上的文件可能需要特殊权限
- 某些文件可能是只读的
- 尝试将文件移动到内部存储

## 📱 权限与隐私

### 为什么 Rhythm 需要存储权限？

用于访问并播放你的音乐文件。Android 13+ 使用 `READ_MEDIA_AUDIO`（音乐和音频），API ≤32 使用 `READ_EXTERNAL_STORAGE`；Android 11+ 使用分区存储 (scoped storage)。**Go 模式不扫描本地曲库，无需该权限**。详见[权限指南](Permissions.md)。

### Rhythm 会收集我的数据吗？

**不会。** Rhythm 是 100% 自由开源软件(FOSS)且注重隐私：
- ✅ 无分析或跟踪
- ✅ 不收集个人数据
- ✅ 所有数据存储在本地
- ✅ 仅可选功能（歌词、封面）使用网络

### 我可以完全离线使用 Rhythm 吗？

可以！核心功能无需网络即可使用：
- 音乐播放
- 播放列表
- 均衡器
- 小部件
- **Rhythm Go** 下载的流媒体曲目

仅以下功能需要网络（外部 API 默认关闭）：
- 在线歌词（LRCLib / BetterLyrics / Lyrically）
- 封面与元数据获取（Deezer、YouTube Music 等）
- 应用更新
- Go 模式服务器连接与在线流媒体播放

### Rhythm 有睡眠定时器吗？

有！从播放界面 → 菜单 → 睡眠定时器 进入。

### 我可以创建和管理播放列表吗？

### Rhythm 支持 Android Auto 吗？

支持！Rhythm 支持 Android Auto。

### 有小部件吗？

有！提供多种小部件：
- **Glance 小部件**：音乐、Cookie、统计和歌词小部件，具有自适应响应式尺寸
- **实时更新**
- **播放控制**
- **可自定义外观**

### 我可以自定义主题吗？

可以！全面的主题定制：
- 浅色/深色/系统模式
- Material You 动态颜色（Android 12+）
- 自定义配色方案
- 字体选择
- Material Symbols 图标
- 节日季节性主题

### 有 A–Z 滚动条吗？

有！当你的音乐库超过一定数量时，歌曲、专辑和艺术家标签页右侧会出现字母滚动条。沿字母滑动手指即可跳转到以该字母开头的条目。

### 什么是 Rhythm Go？

Go 模式把 Rhythm 连接到流媒体服务：**Subsonic 兼容服务**（含 Navidrome / Gonic / Airsonic，需服务器 URL + 用户名 + 密码）、**Jellyfin**（账号认证）与**网易云音乐**（二维码登录，无需服务器 URL）。支持附近服务器发现、流媒体质量设置与「仅离线」模式；Rhythm Go 下载可把服务器曲目保存到设备离线播放。入口：设置 → 高级 → 实验性功能 → Go 模式。

## 🔧 故障排除

### 应用不断崩溃，怎么办？

1. 更新到最新版本
2. 清除应用缓存（不是数据）
3. 检查存储空间（需要 500MB+ 可用空间）
4. 重启设备
5. 如果仍然存在，请向维护者反馈并附上日志

### 扫描后音乐库为空？

1. 授予存储权限：设置 → 应用 → Rhythm → 权限
2. 检查黑名单/白名单：Rhythm 设置 → 库与媒体 → 媒体扫描
3. 确认音乐位置（如 /Music 等标准文件夹）
4. 重新扫描媒体：设置 → 库与媒体 → 媒体扫描

### 小部件不更新？

1. 移除并重新添加小部件
2. 关闭电池优化：设置 → 应用 → Rhythm → 电池 → 不受限
3. 授予通知权限
4. 更新到最新版本

### 蓝牙自动播放不工作？

1. 启用：Rhythm 设置 → 队列与播放 → 播放 → 设备重连时恢复播放
2. 授予蓝牙权限
3. 确保设备已正确配对
4. 检查特定设备的设置

## 🌐 在线功能

### 什么是 LRCLib？

LRCLib 是一个社区驱动的同步歌词数据库。Rhythm 会在可用时从中获取同步歌词。

### Rhythm 会上传我的收听数据吗？

**不会。** 所有统计数据和数据都保留在你的设备上，不会上传到任何服务器。

### 为什么 Rhythm 需要网络访问？

仅用于可选功能：
- **歌词**：LRCLib、BetterLyrics、Lyrically
- **封面 / 元数据**：Deezer、YouTube Music、iTunes、Spotify 搜索、Wikipedia 艺人简介
- **应用更新**：GitHub 版本检查与 APK 下载
- **Go 模式**：Subsonic 兼容服务 / Jellyfin / 网易云音乐

这些外部 API 默认关闭，需在「API 管理」中开启（三层门控）。核心播放不需要联网；可通过防火墙屏蔽网络实现完全离线使用。自托管服务器允许明文 HTTP 与用户 CA。
