# Rhythm 桌面小部件

Rhythm 在 `:feature:widget` 中提供 **4 款 Glance 小部件**与 **1 个 Quick Settings 磁贴**，全部基于 Material 3 Expressive 与系统动态颜色。

---

## 📱 小部件类型

| 小部件 | 特点 |
|:---|:---|
| **音乐小部件** (`RhythmMusicWidget`) | 自适应尺寸，展示封面 / 标题 / 艺术家 / 专辑，含上一曲、播放/暂停、下一曲、收藏、随机、循环；播放时形状动态变化 |
| **歌词小部件** (`RhythmLyricsWidget`) | 多行歌词 + 当前行高亮，随播放位置更新，附歌曲信息与封面 |
| **Cookie 小部件** (`RhythmCookieWidget`) | 12 边形「cookie」背景铺满封面，右上圆形徽章播放/暂停，底部圆徽章切歌；独立的 16 MiB 高清封面缓存 |
| **统计小部件** (`RhythmStatsWidget`) | 12 边形 + 中央 sunny 形状显示总收听时长，右下 gem 徽章显示连续天数；直读 `PlaybackStatsRepository` |

另有 **`RhythmTileService`**：Quick Settings 快捷磁贴，显示当前曲名与播放状态，点击切换播放/暂停；没有有效歌曲时打开主界面。

---

## 🎨 自适应布局

音乐小部件使用 `SizeMode.Exact`，内置 **11 个尺寸断点**（`VERY_THIN` … `HUGE`，约覆盖 1×1 至 5×5+ 单元格），会随你拖动调整大小自动切换布局：

| 尺寸 | 典型展示 |
|:---|:---|
| 极窄 / 超薄 | 曲名 + 播放/暂停，最小占用 |
| 2×2 | 封面 + 曲名 + 基础控制 |
| 3×2 / 4×2 | 横向布局，完整元数据与控制按钮 |
| 3×3 / 4×4 / 5×5+ | 大封面、完整曲目信息、大尺寸控制 |

Cookie / 统计小部件为 2×2（110×110dp）；歌词小部件最小 180×80dp，推荐 3×2。所有小部件均支持系统圆角与动态颜色。

## 🔧 添加小部件

### Android 12+

1. 桌面**长按** → 点按 **Widgets（小部件）**
2. 找到 **Rhythm**，选择 Music / Cookie / Stats / Lyrics Widget
3. 拖到桌面，使用角柄调整大小
4. 如需快捷开关，下拉快速设置面板 → 编辑 → 添加 **Rhythm** 磁贴

### Android 8–11

1. 桌面空白处**长按** → **Widgets**
2. 长按 **Rhythm** 小部件并拖到桌面
3. 使用角 / 边缘手柄调整大小

> 部分启动器对小部件尺寸的处理不同；若显示被拉伸，尝试换一个尺寸档位或启动器。

## ⚙️ 小部件设置

入口：**Rhythm → 设置 → 主页与小部件 → 小部件设置**

可调整圆角、背景透明度、封面显示、曲目信息显示，以及统计小部件的时间范围；Cookie 小部件还可配置角落按钮的动作（切歌 / 随机 / 循环 / 收藏 / 无）。具体可选值与默认值以应用内当前界面为准。

---

## 🔄 更新机制

小部件**不做周期轮询**：4 个 `appwidget-provider` 的 `updatePeriodMillis` 均为 `0`，由播放状态变更推送：

- 曲目切换、播放 / 暂停、封面或元数据更新 → `GlanceWidgetUpdater` 直接写入 Glance state 并 `updateAll()`
- 歌词行推进 → `updateLyrics()` 单独刷新歌词小部件
- `RhythmWidgetWorker`（`CoroutineWorker`）只用于**一次性延迟兜底刷新**（`OneTimeWorkRequest`），仓库中**没有** `PeriodicWorkRequest`
- 磁贴监听 `widget_prefs` 的播放状态与曲名变化自行更新

因此电池占用很低，也不会在 Doze 下被定时任务拖累。

## 🐛 故障排查

### 小部件不更新

1. **关闭电池优化**：系统设置 → 应用 → Rhythm → 电池 → 「不受限」
2. **授予通知权限**（Android 13+）：前台服务与播放通知需要
3. **确认播放服务未被强制停止**：打开应用播放一首歌，再回到桌面
4. **移除并重新添加小部件**

### 显示空白 / 加载中

打开一次 Rhythm 并播放任意曲目，让 `GlanceWidgetUpdater` 推送一次完整状态；若仍空白，检查封面缓存与启动器兼容性。

### 控制按钮无响应

确认应用未被强制停止、通知权限已授予；必要时重启设备后重新添加小部件。

### 布局被拉伸或裁剪

调整到另一个尺寸断点、换启动器，或在问题追踪中反馈具体启动器与尺寸。

## 💡 最佳实践

- **手机竖屏**：3×2 或 4×2 音乐小部件
- **手机横屏**：4×2 或更宽布局
- **平板 / 折叠屏展开**：4×4 以上大尺寸音乐小部件
- **只想看歌词**：歌词小部件 3×2
- 把小部件放在常看位置，并选择与圆角 / 透明度设置相配的壁纸
