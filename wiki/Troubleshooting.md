# 故障排除指南

本指南介绍 Rhythm 音乐播放器的常见问题(issue)与解决方法。

## 🔍 快速诊断

在深入排查具体问题之前，先尝试这些通用修复方法：

1. **重启应用**：完全关闭后重新打开
2. **检查权限**：设置 → 应用 → Rhythm → 权限
3. **更新应用**：确保使用的是最新版本
4. **清除缓存**：设置 → 应用 → Rhythm → 存储 → 清除缓存
5. **重新扫描媒体**：Rhythm 设置 → 音乐库与媒体 → 媒体扫描

---

## 📁 权限问题

### 音乐库无法加载

**症状：**
- 扫描后音乐库为空
- 提示"未找到歌曲"
- 无法播放任何音乐

**解决方法：**
1. **手动授予存储权限：**
   - Android 设置 → 应用 → Rhythm → 权限
   - 启用"文件和媒体"或"存储"
   - 重启 Rhythm

2. **检查文件夹访问权限（Android 14+）：**
   - 你可能只授予了部分访问权限
   - 重新授予完整的音乐文件夹访问权限

3. **确认音乐位置：**
   - 确保音乐位于标准位置（`/Music`、`/Download`）
   - 检查这些文件夹是否在 Rhythm 设置中被列入黑名单

4. **重新扫描媒体：**
   - Rhythm → 设置 → 音乐库与媒体 → 媒体扫描
   - 等待扫描完成
   - Rhythm 会执行**全量扫描**以可靠地捕获所有更改

### 通知控制不工作

**症状：**
- 通知中没有播放控制按钮
- 通知不显示

**解决方法：**
1. **授予通知权限：**
   - 设置 → 应用 → Rhythm → 权限
   - 启用"通知"

2. **检查通知设置：**
   - 确保通知未被阻止
   - 检查勿扰模式设置

3. **重启前台服务：**
   - 完全停止播放
   - 关闭应用
   - 重新打开并开始播放

## 🎵 播放问题

### 音乐无法播放

**症状：**
- 歌曲看似加载了但没有声音
- 播放立即停止
- 出现错误信息

**解决方法：**
1. **检查音频格式：**
   - 参见[音频格式指南](Audio-Formats.md)
   - 不支持的格式无法播放
   - 转换为 FLAC 或 MP3

2. **验证文件完整性：**
   - 尝试在其他应用（VLC）中播放
   - 如文件损坏，请重新下载

3. **检查音频输出：**
   - 确保音量未被静音
   - 尝试其他输出设备
   - 断开/重新连接蓝牙

4. **清除音频缓存：**
   - 设置 → 应用 → Rhythm → 存储
   - 清除缓存（不是数据）

### 音频卡顿/故障

**症状：**
- 噼啪或爆音
- 间歇性停顿
- 声音中断

**解决方法：**
1. **减少后台进程：**
   - 关闭其他应用
   - 为 Rhythm 关闭电池优化

2. **检查存储空间：**
   - 确保有足够的可用空间（500MB 以上）
   - 必要时清除缓存

3. **禁用音频效果：**
   - 暂时关闭均衡器
   - 禁用低音增强/虚拟化

4. **尝试不同的音频缓冲：**
   - 某些设备需要更大的缓冲区
   - 查看设备制造商的相关设置

### 无缝播放不工作

**症状：**
- 曲目之间有短暂的静音
- 专辑曲目之间衔接不流畅

**解决方法：**
1. **检查格式兼容性：**
   - 无缝播放在 FLAC、MP3、AAC 上效果最好
   - 某些格式不支持无缝播放

2. **验证专辑元数据：**
   - 确保曲目标记为同一专辑
   - 检查曲目编号是否连续

3. **更新 ExoPlayer：**
   - 更新到最新的 Rhythm 版本
   - 新版本中包含 ExoPlayer 的改进

## 📊 元数据与封面问题

### 专辑封面不显示

**症状：**
- 显示通用占位图而不是专辑封面
- 部分专辑显示封面，部分不显示

**解决方法：**
1. **检查内嵌封面：**
   - 使用 MP3Tag 或类似工具确认封面已内嵌
   - 如缺失，请嵌入封面

2. **启用在线封面：**
   - Rhythm → 设置 → 通知与服务 → API 管理
   - 启用"从 Deezer 获取专辑封面"

3. **清除图片缓存：**
   - 设置 → 应用 → Rhythm → 存储 → 清除缓存
   - 重新扫描音乐库

4. **检查文件权限：**
   - 确保 Rhythm 已获得音频访问权限
   - 在设置中重新扫描音乐库

### 元数据不正确

**症状：**
- 歌曲标题、艺术家或专辑错误
- 信息缺失
- 无法编辑元数据

**解决方法：**
1. **在 Rhythm 中编辑元数据：**
   - 长按歌曲 → 歌曲信息 → 编辑
   - 更新标题、艺术家、专辑等
   - 需要存储写入权限

2. **使用桌面端元数据编辑器：**
   - **Windows/Mac：**[Mp3tag](https://www.mp3tag.de/)
   - **跨平台：**[MusicBrainz Picard](https://picard.musicbrainz.org/)
   - 编辑后重新扫描音乐库

3. **检查文件编码：**
   - 确保标签使用 UTF-8 编码
   - 特殊字符可能导致问题

4. **批量编辑：**
   - 使用 MusicBrainz Picard 自动标记
   - 将文件与在线数据库匹配

### 无法编辑元数据

**症状：**
- 编辑选项呈灰色不可用
- 更改无法保存
- "权限被拒绝"错误

**解决方法：**
1. **授予写入权限：**
   - Android 设置 → 应用 → Rhythm → 权限
   - 确保已授予存储写入权限

2. **检查文件位置：**
   - SD 卡上的文件可能需要特殊权限
   - 尝试移动到内部存储

3. **验证文件权限：**
   - 某些文件可能是只读的
   - 在文件管理器中检查文件属性

## 🎤 歌词问题

### 歌词无法加载

**症状：**
- 提示"未找到歌词"
- 歌词界面为空

**解决方法：**
1. **启用歌词来源：**
   - Rhythm → 设置 → 音频与效果 → 歌词
   - 启用 LRCLib 和内嵌歌词

2. **检查网络连接：**
   - LRCLib 需要联网
   - 确认连接已激活

3. **尝试手动搜索：**
   - 点按"搜索歌词"按钮
   - 手动输入艺术家和标题

4. **检查内嵌歌词：**
   - 使用 MP3Tag 确认歌词已内嵌
   - 必要时手动嵌入

### 歌词不同步

**症状：**
- 歌词出现过早/过晚
- 高亮显示与音频不匹配

**解决方法：**
1. **调整同步偏移：**
   - 点按歌词设置图标
   - 使用 +/- 按钮调整时间
   - 为该曲目保存偏移量

2. **尝试其他来源：**
   - 在 LRCLib 和内嵌歌词之间切换
   - 某些来源的时间轴更准确

3. **编辑 .lrc 文件：**
   - 使用 LRC 编辑器修正时间戳
   - 保存修正后的版本

## 🔄 更新与安装问题

### 更新无法安装

**症状：**
- "应用未安装"错误
- 安装被阻止
- "软件包冲突"错误

**解决方法：**
1. **检查签名是否匹配：**
   - 不同来源的更新具有不同的签名
   - 如果更换来源，请卸载后全新安装

2. **启用未知来源：**
   - 设置 → 安全性 → 安装未知应用
   - 为你的浏览器/文件管理器启用

3. **清除下载缓存：**
   - 删除旧的 APK 文件
   - 重新下载更新

4. **足够的存储空间：**
   - 确保有 100MB 以上的可用空间
   - 清理不必要的文件

### 自动更新不工作

**症状：**
- 没有更新通知
- 更新检查失败

**解决方法：**
1. **检查更新设置：**
   - Rhythm → 设置 → 更新与信息 → 更新
   - 启用自动更新检查

2. **验证网络访问：**
   - 需要能够访问更新服务
   - 检查防火墙/VPN 设置

3. **手动检查：**
   - 设置 → 更新与信息 → 关于 → 检查更新
   - 必要时手动下载

## 📱 小部件问题

### 小部件不更新

**症状：**
- 小部件显示旧的歌曲
- 播放/暂停按钮不工作
- 小部件似乎卡住了

**解决方法：**
1. **重启小部件：**
   - 从桌面移除小部件
   - 重新添加小部件

2. **检查电池优化：**
   - 设置 → 应用 → Rhythm → 电池
   - 设为"不受限制"或"不优化"

3. **验证小部件权限：**
   - 小部件需要通知访问权限
   - 在应用权限中授予

4. **更新 WorkManager：**
   - 更新到最新的 Rhythm 版本
   - 近期版本改进了小部件更新

### 小部件尺寸显示错误

**症状：**
- 小部件显示被拉伸或裁剪
- 控件被截断

**解决方法：**
1. **调整小部件大小：**
   - 长按小部件 → 调整大小手柄
   - 拖动到正确的尺寸

2. **尝试不同布局：**
   - 移除并重新添加小部件
   - 选择合适的尺寸（2x1 到 5x5）

3. **启动器兼容性：**
   - 某些启动器存在小部件尺寸问题
   - 尝试其他启动器

## 🎧 蓝牙与音频输出

### 连接蓝牙后自动播放不工作

**症状：**
- 连接蓝牙后音乐不恢复
- 没有自动播放行为

**解决方法：**
1. **启用自动恢复播放：**
   - Rhythm → 设置 → 队列与播放 → 播放
   - 启用"设备重连时恢复播放"

2. **授予蓝牙权限：**
   - 设置 → 应用 → Rhythm → 权限
   - 启用蓝牙访问

3. **检查设备配对：**
   - 确保蓝牙设备已正确配对
   - 必要时重新连接

### 音频路由问题

**症状：**
- 声音从错误的扬声器播放
- 无法切换到蓝牙
- 音频输出卡住

**解决方法：**
1. **通过系统音量面板选择输出：**
   - 打开 Android 音量面板并点按输出图标
   - 选择蓝牙设备

2. **重启蓝牙：**
   - 关闭再打开蓝牙
   - 重新连接设备

3. **清除音频缓存：**
   - 重启 Rhythm
   - 断开所有蓝牙设备
   - 重新连接目标设备

### USB DAC 支持与 Android 弹窗

**症状：**
- USB DAC 已连接，但没有出现 Android USB 权限对话框（例如"允许 Rhythm 访问 [USB 设备]？"）。

**说明与验证：**
1. **静默原生路由：**Rhythm 使用标准 Android 系统音频路由和 Android 14 的原生 `setPreferredMixerAttributes` API（应用模式）将音频原生路由到 USB DAC。由于这依赖于官方的系统级 API，而不是自定义的用户空间 USB 驱动，**因此不会（也不需要）弹出 USB 权限对话框。**DAC 会静默接收高分辨率播放。
2. **验证播放：**你可以通过查看 DAC 硬件 LED 的颜色/指示灯，或确认设置中**实验性功能**下的"DAC / USB Audio"设置已配置，来验证 DAC 是否处于活动状态。

## 💾 备份与恢复

### 备份失败

**症状：**
- "备份失败"错误
- 未创建备份文件

**解决方法：**
1. **检查存储权限：**
   - 确保已授予写入权限
   - 确认目标文件夹存在

2. **足够的存储空间：**
   - 确保有足够的可用空间
   - 备份文件可能有几 MB

3. **尝试其他位置：**
   - 使用内部存储而不是 SD 卡
   - 某些文件夹可能有限制

### 恢复不工作

**症状：**
- 恢复后播放列表不出现
- 设置未恢复
- "无效备份文件"错误

**解决方法：**
1. **验证备份文件：**
   - 确保文件未损坏
   - 检查文件大小是否合理

2. **版本兼容：**
   - 从相近 Rhythm 版本创建的备份恢复
   - 主版本号差异可能导致问题

3. **手动恢复：**
   - 将播放列表导出为 M3U/PLS
   - 逐个导入

## 🔧 高级故障排查

### 完全重置应用

如果其他方法都无效：

1. **备份重要数据：**
   - 导出所有播放列表
   - 保存设置截图

2. **清除应用数据：**
   - 设置 → 应用 → Rhythm → 存储
   - 清除缓存 → 清除数据

3. **重新安装应用：**
   - 完全卸载 Rhythm
   - 下载全新的 APK
   - 重新安装并设置

⚠️ **警告：**这会清除所有应用数据、播放列表和设置！

### Logcat 调试（高级）

适用于开发者或顽固问题：

```bash
# Capture Rhythm logs
adb logcat | grep "chromahub.rhythm"

# Save to file
adb logcat -d > rhythm_log.txt

# Filter for errors only
adb logcat *:E | grep "chromahub.rhythm"
```

提交问题时附上日志以便调试。
